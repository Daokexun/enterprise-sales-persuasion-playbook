# Enterprise Sales Persuasion Playbook Architecture

## 核心设计哲学
说服不是逼迫对方就范，而是**“发现对方的利益卡点，用你的方案成为对方达成目标的最佳搭档”**。

```mermaid
flowchart TD
    A[客户沟通 / 方案竞标 / 跨部门协作卡点] --> B[Step 1: KP 决策链诊断 (Decision Mapping)]
    B --> C[Step 2: 顾问式销售五步法 (5-Step Consultative)]
    C --> D[Step 3: 异议拆弹与谈判矩阵 (Objection Handling)]
    D --> E[Step 4: 跨部门利益捆绑与资源撬动 (Cross-Team Leverage)]
    E --> F[大单商业闭环 & 职场全栈影响力]
```
