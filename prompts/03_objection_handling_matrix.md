# Prompt 03: 异议拆弹谈判矩阵 (Objection-to-Opportunity Matrix)

## 三大高频异议与拆弹话术
1. **“你们的东西太贵了，预算不够”**
   - 拆解策略：将采购单价转化为 TCO 全生命周期成本对比与单次故障损失规避。
2. **“我们已经有合作很多年的老供应商了”**
   - 拆解策略：肯定老供应商贡献，顺势引入“双活容灾/赛马机制”，请求一个边缘非核心业务的切片验证。
3. **“现在不是做这个的好时机，下半年再说吧”**
   - 拆解策略：量化“延迟成本（Cost of Delay）”，用窗口期紧迫性与行业标杆竞品动作激发紧迫感。
